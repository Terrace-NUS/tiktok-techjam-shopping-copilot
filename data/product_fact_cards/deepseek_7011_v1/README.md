# DeepSeek Product Fact Cards 7011 v1

This bundle contains 7,011 product fact cards generated by DeepSeek V4 Flash with
`product_fact_card_v1_1` and the shared `shopping_facet_language_v1` contract.

The bundle is deliberately a sidecar. It does not rewrite or enrich any row in the
competition catalogue. `load_product_fact_sidecar()` reads the compressed JSONL and
revalidates every fact's `source_id`, `source_ref`, and quoted evidence against the
local immutable `data/catalog.jsonl` before the card can influence retrieval.

Generation proposed 70 facts whose evidence could not be restored as an exact source
substring. The deterministic decoder discarded those facts. The release bundle keeps
only the remaining grounded facts, strips provider response IDs and token-accounting
metadata, and records the discarded-fact count in `manifest.json`.

```python
from shopping_copilot.catalog.product_facts import load_product_fact_sidecar

cards = load_product_fact_sidecar(
    "data/product_fact_cards/deepseek_7011_v1/product-facts.jsonl.gz",
    catalog_path="data/catalog.jsonl",
)
```

Coverage is partial: products without a released card continue to use the original
catalogue-derived retrieval document.
